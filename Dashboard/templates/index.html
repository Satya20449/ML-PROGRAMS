About Project

Student Placement Prediction using Machine Learning

🎓 Project Name

PlacementAI – Student Placement Prediction System

🎯 Objective

The main objective of this project is to analyze student academic and performance data using Exploratory Data Analysis and Machine Learning techniques to understand factors influencing student placement.

📊 Exploratory Data Analysis

The EDA includes missing value analysis, duplicate analysis, feature distributions, outlier detection, correlation analysis, placement analysis, SGPA trends and salary package analysis.

🤖 Machine Learning

The dataset can be used to train Machine Learning models for predicting student placement status based on academic, technical and personal performance features.
