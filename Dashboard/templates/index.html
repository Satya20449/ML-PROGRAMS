About Project

Student Placement Prediction using Machine Learning

🎓 Project Name

PlacementAI – Student Placement Prediction System

🎯 Objective

The main objective of this project is to analyze student academic, technical and performance data using Exploratory Data Analysis, preprocessing, clustering and Machine Learning techniques.

⚙️ Data Preprocessing

The preprocessing stage handles missing values, numerical outliers, normalization and conversion of categorical features into numerical values. The processed dataset is stored as placement_preprocessed.csv.

📊 Exploratory Data Analysis

The EDA includes missing value analysis, duplicate analysis, feature distributions, outlier detection, correlation analysis, placement analysis, SGPA trends and salary package analysis.

🤖 Machine Learning

Several Machine Learning algorithms are implemented for classification and regression, including Decision Tree, AdaBoost, Bagging, Boosting, Gradient Boosting, Logistic Regression and Linear Regression.

🔵 Clustering

K-Means clustering is used to group students based on selected performance features. The project also includes Elbow Method based K calculation and K-Means based outlier detection.
